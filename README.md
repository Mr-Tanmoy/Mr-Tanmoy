### 🦀 TechScript 2.0 — Flagship

My own programming language, built from scratch in Rust — plain-English syntax, compiled to bytecode, run on a custom VM.

```
make name = ask "What is your name? "
say f"Hello, {name}! Welcome to TechScript 2.0 🐉"

each i in 1..10 {
    when i equals 5 { stop }
    say f"Count: {i}"
}
```

**Implemented:**
- Lexer, parser, AST
- Bytecode compiler + stack-based VM (native Rust)
- Standard library, package manager
- CLI compiler (`tech run / check / repl / transpile / version`)
- `use web` module for building websites in TechScript
- TechScript Studio — a docking IDE built with `egui` + `egui_dock`, with an AST/Bytecode inspector

**Planned / expanding:**
- LLVM backend
- JIT compiler
- Language Server Protocol (LSP) support
